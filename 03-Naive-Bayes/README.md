# Naïve Bayes Sentiment Classification

## Overview

This project explores probabilistic machine learning through the implementation of a Naïve Bayes classifier for sentiment analysis. Using Bayes’ Theorem, the model predicts whether movie reviews express positive or negative sentiment.

## Objective

Build and evaluate a Naïve Bayes classifier for sentiment prediction using text data.

## Methods

### Data Processing
- Prepared movie review datasets
- Extracted relevant features from text
- Organized data for classification tasks

### Probabilistic Modeling
- Applied Bayes’ Theorem
- Estimated class probabilities
- Modeled feature distributions using Gaussian probability density functions

### Validation
- Performed 2-fold cross-validation
- Evaluated predictive performance across multiple data splits
- Measured classification accuracy

## Technologies Used

- Python
- NumPy
- Statistical Modeling
- Natural Language Processing

## Skills Demonstrated

- Probabilistic Machine Learning
- Bayesian Statistics
- Cross Validation
- Classification
- Predictive Modeling

## Key Achievement

Achieved approximately 82% classification accuracy across validation folds.
