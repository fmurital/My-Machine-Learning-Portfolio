# K-Nearest Neighbors for Sentiment Analysis

## Overview

This project applies the K-Nearest Neighbors (KNN) algorithm to classify movie reviews as either positive or negative. The objective was to explore supervised machine learning techniques for text classification and evaluate the effectiveness of distance-based learning.

## Objective

Predict the sentiment of movie reviews using a custom implementation of the K-Nearest Neighbors algorithm.

## Methods

### Data Preparation
- Processed movie review text data
- Converted text documents into numerical feature representations
- Prepared labeled datasets for supervised learning

### Model Development
- Implemented the K-Nearest Neighbors algorithm
- Calculated distances between observations
- Assigned sentiment labels based on nearest neighbors

### Evaluation
- Measured classification performance using accuracy metrics
- Compared predictions against known sentiment labels
- Evaluated model performance across test samples

## Technologies Used

- Python
- NumPy
- Pandas
- Scikit-Learn
- Natural Language Processing

## Skills Demonstrated

- Supervised Learning
- Classification
- Text Analytics
- Feature Engineering
- Model Evaluation

## Key Achievement

Achieved approximately 80% accuracy in sentiment classification of movie reviews.
